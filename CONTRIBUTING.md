# Contributing to Broadsheet

Bug reports, Obsidian version compatibility notes, and styling feedback are welcome through [GitHub Issues](https://github.com/KilianTheMagnificent/broadsheet-obsidian-theme/issues).

When opening an issue, please include:

- Your Obsidian version and operating system (desktop or mobile)
- Whether you are using **Day** (light) or **Night Print** (dark) mode
- Any enabled Style Settings options or companion CSS snippets
- Steps to reproduce and a cropped screenshot showing the layout or contrast issue (with private notes removed)

Outside pull requests are turned off. Andre Romero directs development with AI coding assistance and does not accept outside code pull requests because he cannot personally review incoming code changes.

For security concerns, please use the private reporting instructions in [SECURITY.md](SECURITY.md).
