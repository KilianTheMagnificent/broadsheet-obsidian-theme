# Security Policy

## Scope

Broadsheet is a static CSS theme for Obsidian (`theme.css`, `manifest.json`, and optional companion CSS snippets). It contains no executable JavaScript, makes no external network or font requests, and does not handle logins, encryption, backups, or passwords.

## Reporting a Vulnerability

If you spot a security or privacy issue in this repository (for example, an unintended external resource load, CSS data exfiltration vector, or workflow flaw), please report it privately via GitHub's [Private Vulnerability Reporting](https://github.com/KilianTheMagnificent/broadsheet-obsidian-theme/security/advisories/new) instead of opening a public issue.
